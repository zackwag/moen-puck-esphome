# Agents

## Project Overview

ESPHome firmware for the Moen Smart Leak Detector (ESP32-WROVER puck). Replaces stock cloud firmware with a fully local Home Assistant integration via HTTP OTA flashing.

## Architecture

- **moen-puck.yaml** — ESPHome device config. All sensor/output definitions live here.
- **flash_ota.py** — Python script that reads the puck's serial number from its HTTP API, sets the hostname, compiles ESPHome, and flashes the binary via `POST /puck/v1/fwUpdate`.
- **setup.sh** — Interactive first-time setup: prompts for WiFi, generates `secrets.yaml`, compiles firmware.
- **secrets.yaml** — Gitignored. Contains WiFi credentials, API key, device name. Generated by `setup.sh`, updated by `flash_ota.py`.

## Hardware (ESP32-WROVER rev1.0)

| GPIO | Function | Notes |
|------|----------|-------|
| 12 | Blue LED | Active-low, strapping pin |
| 13 | Red LED | Active-low |
| 18 | Buzzer | Active-high piezo |
| 27 | Water sensor | Binary, active-high when wet |
| 32 | Battery ADC | ~3.0V fresh, ~1.8V cutoff |
| 33 | Sensor power | Must stay as ADC input to power H/T circuit |
| 34 | Button | Input-only |
| 35 | Humidity ADC | Calibrated analog sensor |
| 16, 17 | PSRAM | Do not use |
