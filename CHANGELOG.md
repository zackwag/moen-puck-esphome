# Changelog

## [3.0.0](https://github.com/zackwag/moen-puck-esphome/releases/tag/v3.0.0) (2026-10-14)

### Features

* ESPHome firmware for Moen Smart Leak Detector (puck)
* Humidity sensor (GPIO 35, calibrated ADC)
* Water leak detection (GPIO 27)
* Battery percentage monitoring (GPIO 32)
* Red and blue LED control (GPIO 13, 12)
* Piezo buzzer control (GPIO 18)
* Button input (GPIO 34)
* WiFi with fallback AP, Home Assistant API, web server, OTA updates
* OTA flash script for initial install from stock Moen firmware
* Automatic hostname from puck serial number
